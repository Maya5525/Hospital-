# 🏥 Hospital Analytics Platform

An end-to-end hospital analytics application built with **Python**, **Machine Learning**, and **Streamlit**. The project analyzes hospital service data, provides interactive dashboards and visual insights, and uses Machine Learning to predict the number of patients admitted.

---

## 📌 Project Overview

This project analyzes hospital service data and provides:

* 📊 Interactive KPI Dashboard
* 📈 Patient Admission Analysis
* 🏥 Hospital Service Performance Analysis
* 🤖 Machine Learning Prediction
* 💡 Automated Business Insights
* 🎯 Data Filtering & Visualization

The application helps hospital management understand patient demand, hospital capacity, service performance, and admission patterns to support data-driven decisions.

## 🤖 Machine Learning

The project includes a **Regression Model** that predicts the number of **Patients Admitted** based on hospital service and operational information.

### Target

* Patients Admitted

### Features Used

* Week
* Month
* Service
* Available Beds
* Patients Request
* Patients Refused
* Staff Morale
* Event

### Algorithm

* Gradient Boosting Regressor

### Evaluation Metrics

* MAE (Mean Absolute Error)
* RMSE (Root Mean Squared Error)
* R² (R-squared)

## ▶️ Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

Move to the project folder:

```bash
cd Hospital-Analytics
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
